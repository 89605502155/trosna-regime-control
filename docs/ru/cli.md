# Командная строка

[English version](../en/cli.md) · [README](../../README.ru.md)

```sh
trosna-regime-control --version
trosna-regime-control analyze checks.csv [параметры]
trosna-regime-control flicker [--heuristic config.json] [--rate 0.05 ...] [--json]
```

То же запускается как `python -m trosna_regime_control`. Код возврата 0 — успех,
2 — неверный вход; сообщение выводится в поток ошибок.

## analyze

Читает файл `checks.csv` (формат в [log_format.md](log_format.md)) и печатает:

* число проверок, долю перераспределений, средний интервал;
* наивную и скорректированную оценки интенсивности в конце трассы;
* проверку модели: наклон `ln Δt` (модель: 1), коэффициент предыдущего бита
  (модель: 0) и согласованность модели;
* контроллер, прогнанный на тех же решениях: тревоги, переключения режима в час,
  долю нестационарных проверок;
* эвристику из пяти битов на тех же решениях: переключения в час и долю
  нестационарных проверок. Если есть столбец `mode`, используется он.

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--tau` | 1800 | память оценки интенсивности, с |
| `--rule` | A | правило интервала, `A` или `B` |
| `--p-star` | 0.3 | вероятность хода за интервал, в `(0, 1)`, для правила А |
| `--formula` | exact | правило А: `exact` (`-ln(1-p*)/λ`) или `linear` (`p*/λ`) |
| `--scale` | 1.0 | положительный множитель интервала правила А |
| `--estimator` | debiased | оценка для правила: `debiased` или `naive` (`N/T`) |
| `--c1-over-c2` | 2.0 | отношение затрат для правила Б, с |
| `--arl` | 3600 | среднее время до ложной тревоги детектора, с |
| `--confidence` | 0.95 | односторонний уровень доверия базовых уровней детектора, в `[0.5, 1)` |
| `--z` | — | число стандартных отклонений базовых уровней; заменяет `--confidence` |
| `--hold` | 300 | сколько длится нестационарный режим после тревоги, с |
| `--warmup` | 600 | время наблюдения до включения детектора, с |
| `--heuristic` | встроенная | JSON-файл с таблицей текущей эвристики |
| `--burn-in` | 10 | сколько проверок пропустить в проверке модели |
| `--json` | выкл. | печатать отчёт в JSON |

```sh
trosna-regime-control analyze checks.csv --rule B --c1-over-c2 2 --json
```

## flicker

Считает точные переключения режима текущей эвристики при постоянных интенсивностях,
по цепи Маркова. Без `--rate` печатает 0,01; 0,02; 0,05; 0,1 и 0,2 1/с. Если
таблица условная (`is_real` равно false), выводится примечание.

```sh
trosna-regime-control flicker --heuristic config/heuristic.json --rate 0.05 --rate 0.1
```

## Файл настроек эвристики

```json
{
  "comment": "параметры текущей эвристики",
  "is_real": true,
  "n_bits": 5,
  "interval_by_sum_s": {"0": 10.0, "1": 8.2, "2": 6.4, "3": 4.6, "4": 2.8, "5": 1.0},
  "nonstationary_if_sum_at_least": 3
}
```

`interval_by_sum_s` должен содержать значение для каждой суммы от 0 до `n_bits`.
Поле `is_real` должно быть `true` для результатов, которые идут в статью.
