# Формат журнала

[English version](../en/log_format.md) · [README](../../README.ru.md)

Один файл `checks.csv` содержит одну строку на проверку. Кодировка UTF-8.

| Столбец | Тип | Обязателен | Смысл |
|---|---|---|---|
| `t_unix` | float | да | момент проверки, секунды от эпохи Unix |
| `b` | 0 или 1 | да | 1, если на проверке память перераспределяли |
| `dt_s` | float | нет | реальный интервал перед проверкой, с |
| `s_sum` | int | нет | сумма `S` текущей эвристики после проверки |
| `mode` | 0 или 1 | нет | режим текущей эвристики, 1 — нестационарный |
| `next_dt_s` | float | нет | интервал, выбранный системой, с (не читается) |
| `cycle_cost_s` | float | нет | длительность цикла, с (не читается) |
| `moved_mb` | float | нет | перемещённая память за цикл, МиБ (не читается) |

Правила:

* Если `dt_s` отсутствует, интервал равен разности `t_unix` с предыдущей строкой,
  а первая строка отбрасывается (её время берётся как начало).
* `t_unix` должен возрастать, `dt_s` — быть положительным, `b` — равняться 0 или 1.
* Бит `b` относится к интервалу перед своей проверкой: решение принято по
  статистике этой проверки. Это важно для модели `P(b = 1) = 1 − e^{−λΔt}`.

Пример:

```
t_unix,dt_s,b,s_sum,mode,next_dt_s,cycle_cost_s,moved_mb
1763200000.000,10.000,0,0,0,10.000,0.041,0
1763200010.002,10.002,1,1,0,8.200,0.057,256
1763200018.204,8.202,0,1,0,8.200,0.043,0
```

Чтение в Python:

```python
import pathlib

from trosna_regime_control import read_checks

path = pathlib.Path("checks.csv")
path.write_text(
    "t_unix,dt_s,b\n1763200000.0,10.0,0\n1763200010.0,10.0,1\n",
    encoding="utf-8",
)
trace = read_checks(path)
print(trace.t, trace.dt, trace.decision)
```

Измерения памяти виртуальных машин берутся из статистики баллуна libvirt, например
`virsh domstats --balloon`.
